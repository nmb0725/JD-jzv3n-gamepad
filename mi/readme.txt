JD JZ-V3N Gamepad to Xbox 360 controller Mapper using SCPbus.

This project is a fork/adaptation of the original Xiaomi Gamepad mapper, 
modified to support the JD (Jingdong) JZ-V3N game controller.

Features:
-Rumble support (works perfectly)
-No noticeable input delay
-Tested on Windows 10/11

Libs used:
https://github.com/mogzol/ScpDriverInterface
https://github.com/mikeobrien/HidLibrary/ (modified)

References:
